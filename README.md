## 👨‍💻 About Me

I'm a final-year Computer Science student (graduating in 2027) who enjoys building the part of an application that users never see: the APIs, databases, and architecture that make everything work. I take a backend-first approach to full-stack development, mostly with the MERN stack.

<br>

- 🧩 **What I enjoy:** Backend engineering, API design, and database design.

- 🤖 **What I'm exploring:** LLM integrations, embeddings, and Retrieval-Augmented Generation (RAG).

- ⚙️ **What I'm learning:** Distributed backend architecture and DevOps.
